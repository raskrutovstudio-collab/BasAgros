# Требования к визуальным материалам главной

Для главной подключён локальный оптимизированный набор AVIF/WebP. Источники и лицензии зафиксированы в `site/assets/img/home/SOURCES_AND_LICENSES.md`; отсутствующие или неподтверждённые кадры не подменяются случайными фотографиями и остаются техническими слотами `data-asset-slot`.

Не публиковать кадры, которые создают ложное представление о складе, сотрудниках, документах, производстве или конкретном сорте. Собственного агронома нет: слот представителя — будущий образ сотрудника BAS Agros, не агронома.

Вероятный LCP: `hero-field`. Только этот файл загружается без `lazy` и получает `fetchpriority="high"`. Остальные изображения — `loading="lazy"`; декоративные SVG не имеют priority.

Форматы для всех фото: AVIF + WebP. JPEG не использовать как основной. `srcset`/`sizes`, dimensions, mobile-кадр отдельно. First-screen hero не lazy. Остальные — lazy.

Документные слоты качества (`data-asset-slot="document"`) остаются нейтральными плейсхолдерами. Сканы сертификатов, печати, номера и таблицы показателей не добавлять, пока документы не подтверждены на `/kachestvo-i-sertifikaty/`.

Форма отключена: `enabled: false`, пустой endpoint, submit `disabled`. Fetch не выполняется. Маршрут `/privacy/` отсутствует в утверждённом SEO-манифесте, поэтому согласие показано как отключённое состояние без фиктивной ссылки; до запуска нужны утверждённый документ и отдельный маршрут.

## Оставшиеся утверждаемые материалы

- оригинальный логотип BAS Agros вместо нейтрального inline SVG-знака;
- собственные кадры рабочего процесса BAS Agros для корпоративного коллажа;
- подтверждённая фотография сорго (сейчас технический placeholder);
- нейтральный кадр реальных документов или лабораторной работы без читаемых номеров, печатей и неподтверждённых сертификатов.
