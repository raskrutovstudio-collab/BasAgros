# SEO Optimization
Before changes: identify page type/intent, SEO map/parent/cluster, preserve valuable URLs in migration.

On-page: unique Title/Description, one H1, logical H2-H3, first screen clear,
natural query use, proof/conditions/process/FAQ/CTA when relevant, no hidden text/stuffing.

Technical: 200, crawlable, correct canonical, no accidental noindex,
robots/sitemap not blocking, hreflang by fact, crawlable links, important content in HTML.

Internal links: parent link, logical next step, no orphan, important pages usually <=3 clicks.
