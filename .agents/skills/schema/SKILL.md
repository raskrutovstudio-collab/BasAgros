# Schema Markup
1. Mark up only visible truthful data.
2. Never invent ratings, reviews, prices, availability, employees or addresses.
3. Avoid conflicting duplicate entities.
4. Use stable @id and link entities.
5. Check final DOM.

Use Product only for a specific product, FAQPage only for visible FAQ,
BreadcrumbList for actual path, LocalBusiness only for real local organization.
Validate JSON and rich-results/schema tools when applicable.
