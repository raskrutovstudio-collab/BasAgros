# SEO Audit
Priority: crawl/index → canonical/redirect/duplicates → architecture/internal links →
technical/performance → intent/on-page → content → local/commercial signals.

Check robots/sitemap/status, noindex/canonical/redirect chains/soft404,
duplicate Title/H1/Description/URL, orphan/depth, params, mobile/CWV,
rendered Schema, cannibalization, cluster relevance, doorway risk, local NAP,
analytics after migration.

Do not claim a dynamic element is absent from static HTML alone.
