# Frontend Design Review
Check:
- offer and main CTA clear in 3–5 sec;
- consistent grid/spacing;
- clear H1/H2/body/CTA hierarchy;
- readable typography;
- limited fonts/weights;
- responsive without overlap/horizontal scroll;
- touch-friendly controls;
- images not distorted;
- forms/tables reflow correctly;
- hover/focus/active/disabled/loading/success/error;
- long text/overflow states.
Priorities: Blocking / Major / Minor.
Suggest minimal fixes, not arbitrary redesign.
