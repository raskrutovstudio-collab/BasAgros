# Programmatic SEO
Scale only when each page has unique utility. Name replacement is insufficient.

Before generation:
1. confirm demand and separate intent;
2. define data source;
3. check if one strong page is better;
4. create 3–5 page pilot.

Control:
- unique Title/Description/H1;
- no fake local office/address;
- no empty variables;
- correct canonical/sitemap;
- no orphan pages;
- no cannibalization;
- natural text;
- unique facts have source.
