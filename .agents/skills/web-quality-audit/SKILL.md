# Web Quality Audit
Order:
1. functionality: pages/menu/links/forms/modal/buttons/console/404;
2. performance: critical path/images/fonts/CSS/JS/third-party/cache;
3. CWV root causes;
4. accessibility;
5. SEO/indexability/canonical/schema;
6. security/integrations.

Priorities:
P0 broken site/leads/data leak/index blocked;
P1 serious CWV/form/canonical/mobile;
P2 material SEO/UX/speed;
P3 improvements.

For each issue: proof → impact → fix → regression risk → verification.
