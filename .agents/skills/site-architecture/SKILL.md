# Site Architecture
For each indexable page record: name/type, parent, URL, intent, cluster, indexability,
inbound/outbound links, priority.

Rules:
- one page = one primary intent;
- important pages usually <=3 clicks;
- short stable URLs;
- no page just for one tiny query variant;
- geo pages require real local value;
- cases/articles/FAQ support commercial hubs;
- navigation/breadcrumbs align with architecture;
- migration requires redirect map.
